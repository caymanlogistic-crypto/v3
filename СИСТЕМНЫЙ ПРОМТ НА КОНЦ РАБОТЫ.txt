# Transport ERP Platform v3 — Full Project Context

---

# Project Type

Custom modular ERP/CRM platform for transport and logistics operations.

Main stack:
- PHP 8.4
- Custom MVC-like architecture
- PDO + MySQL
- No Laravel/Symfony
- Modular architecture
- Shared hosting
- Public path:
  `/v3/public`

Project goal:

Build production-quality transport ERP with modern architecture standards while keeping lightweight custom core.

# Additional Architecture Clarifications

## CSRF Protection

Current state:

```text
NOT IMPLEMENTED YET
```

Current POST forms work without CSRF validation.

Planned architecture:

```text
Session-based CSRF tokens
```

Planned components:

```text
app/Core/Security/Csrf.php
app/Core/Middleware/CsrfMiddleware.php
```

Planned helpers:

```php
csrf_token()
csrf_field()
```

Reasoning:
- server-rendered ERP
- simpler architecture
- no SPA complexity
- session-based auth already used

Double-submit cookies are NOT planned.

---

## Request Object

Current Request implementation is minimal/lightweight.

Currently used pattern:

```php
$request->input('name')
```

Current functionality:
- input()
- basic GET/POST wrapper

Not implemented yet:
- validate()
- all()
- only()
- except()
- file()
- query()
- typed DTO mapping

Planned future API:

```php
$request->all()
$request->only([])
$request->except([])
$request->has()
$request->method()
$request->isPost()
```
