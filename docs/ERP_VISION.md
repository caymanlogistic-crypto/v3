# ERP Vision

## Transport ERP goals

- Build a practical lightweight enterprise platform for transport and logistics.
- Support core workflow for contractors, drivers, vehicles, trips, orders, warehouse, finance, documents, notifications, and integrations.
- Keep the system maintainable on shared hosting with PHP 8.4.

## Business direction

- Focus on operational efficiency, reliability, and backend stability.
- Deliver core logistics workflows before adding feature complexity.
- Use modular components to isolate business areas.

## Module ecosystem

Planned modules:

- Contractors
- Orders
- Drivers
- Fleet
- Vehicles
- Trips
- Logistics
- Tracking
- Warehouse
- Finance
- Documents
- Notifications
- Integrations

## Operational UI philosophy

- Desktop-first ERP admin interface.
- Compact tables and compact forms.
- Lightweight CSS and reusable style patterns.
- Avoid random UI templates and large third-party UI frameworks.
- Prioritize usability for back-office operators.

## Scaling direction

- Stabilization and incremental improvement over large rewrites.
- Keep core architecture lightweight and custom.
- Build reusable core components that support future modules.
- Continue using PDO and custom routing while eliminating technical debt gradually.
